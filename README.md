# Data Structures & Algorithms Practice

Custom Java implementations of core data structures and algorithm exercises, built from scratch to understand how they work under the hood.

## Files

| File | Description |
|------|-------------|
| `LinkedListDemo.java` | Custom generic singly linked list (add, remove, get/set at index) |
| `StackDemo.java` | Stack implemented with a resizable array |
| `LinkedStackDemo.java` | Stack implemented with a linked list |
| `QueueDemo.java` | Queue implemented with a linked list |
| `ArrayQueueDemo.java` | Queue implemented with a circular resizable array |
| `BinaryTreeDemo.java` | Generic binary tree with subtree access and serialization |
| `BSTDemo.java` | Binary search tree with add, contains, and delete |
| `PostfixEvalDemo.java` | Evaluates postfix (RPN) expressions using a stack |

## How to Run

Each file is self-contained. Compile and run any one individually, e.g.:
\`\`\`
javac LinkedListDemo.java
java LinkedListDemo
\`\`\`
